How to use this calculator

  1. Orders × AOV = total gross revenue in the period.
  2. Return rate tells you how many orders come back. Multiply to get the number of returns.
  3. Each return costs you: full refund + processing + COGS not recovered − resale value + (optionally) non-refundable platform fees.
  4. Break-even return rate is the threshold above which returns destroy all profit on the product. Below it, you're still earning — just less than you think.

Frequently asked questions

What's a realistic return rate for ecommerce in 2026?

Industry averages in 2026: apparel 24-30%, footwear 20-25%, electronics 11-15%, home goods 8-12%, beauty 4-8%. Apparel stays the worst category because of bracketing (buying multiple sizes to try).

How much does a single return actually cost?

Typical cost is $10-15 per return, counting reverse shipping, processing labor, restocking, and packaging. On top of that, you lose the product cost you can't recover if the item can't be resold at full price.

Do free returns kill profitability?

Free returns lift conversion by a meaningful amount, but also raise the return rate itself. Whether they're worth it depends on whether the extra conversion profit outweighs the higher return cost. Use this calculator with two scenarios: one with your real return rate, one with the rate you'd see without free returns.
